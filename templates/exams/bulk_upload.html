File format guide

One question per row. The first row must be the headers:

question, option_a, option_b, option_c, option_d, option_e, option_f, correct, marks, explanation

  • Required: question, option_a, option_b, correct. Options c to f are optional.
  • correct is a letter (B) or the exact text of the right option.
  • marks and explanation are optional.
Download sample CSV

Write each question in this layout (blank lines between questions are optional):

1. What keyword defines a function in Python?
A. func
B. def
C. lambda
D. fn
Answer: B
Marks: 2
Explanation: def declares a function.

2. Which data type is immutable?
A. list
B. dict
C. tuple
D. set
Answer: C
  • Options run A to F. Answer: is required; Marks: and Explanation: are optional.
  • Type the numbers and letters as text. Word's automatic list numbering isn't stored in the text, so it can't be read. (Exporting to PDF turns it into real text, which does work.)
  • Old .doc files aren't supported: use File → Save As → .docx.
  • Scanned or image-only PDFs aren't supported, because they contain no text to read.
